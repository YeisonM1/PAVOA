Antes de empezar

Preparacion de la prueba

01

Esta preparacion evita confusiones. La idea es probar con datos controlados, anotar evidencia y saber exactamente donde revisar cada resultado.

Accesos necesarios

Datos de prueba

  • Crear o elegir un producto barato para compra real controlada.
  • Tener una variante con stock disponible.
  • Tener una variante sin stock para prueba negativa.
  • Definir nombre, telefono, ciudad, barrio y direccion ficticia pero realista.
  • Guardar fecha y hora de cada prueba.
Regla importante: si un pago queda aprobado pero no aparece en Shopify, Mercado Pago, correo o PAVOA Control, se detienen las pruebas y se revisa antes de seguir.

Orden recomendado

No saltar pasos
Cliente navega y agrega al carritoValidar catalogo, producto, tallas, colores, cantidad y carrito.
Cliente llena checkoutValidar errores, datos obligatorios, resumen y total.
Cliente intenta pagarConfirmar redireccion a Mercado Pago y creacion del draft order.
Admin revisa ShopifyConfirmar producto, variante, direccion, telefono, notas, tags y estado.
Admin revisa PAVOA ControlConfirmar pedido, embudo, newsletter, stock alerts o wishlist segun la prueba.
Admin revisa correo y evidenciaAnotar si llego correo, si el contenido es correcto y si hubo duplicados.

Rondas recomendadas

Que probar primero

08

No hay que probar todo todos los dias. Usa estas rondas segun el momento.

RondaCuando hacerlaIncluyeDuracion
RapidaDespues de un cambio pequeño.Home, producto, carrito, checkout sin pagar.10 min
Compra realAntes de campana o lanzamiento.Compra aprobada completa, Shopify, Mercado Pago, PAVOA Control, correo.25-40 min
Producto nuevoCuando se suben referencias nuevas.Shopify, variantes, stock, catalogo, PDP, carrito.20 min
CompletaSemanal o antes de vender fuerte.Todos los modulos del manual.60-90 min

Primera prueba obligatoria

  • Crear o elegir producto barato.
  • Comprar como clienta invitada.
  • Pagar exitosamente.
  • Verificar Shopify.
  • Verificar Mercado Pago.
  • Verificar PAVOA Control.
  • Verificar correo.

Criterio de aprobado

Criterio de bloqueo: pago aprobado sin pedido operativo, total distinto, checkout roto, producto publicado que no se puede comprar, stock incorrecto o correos duplicados.
